# Data Model: MVP RSS Reader

## Entities

### Subscription

Represents a user-added feed subscription.

| Field | Type | Description | Validation |
|---|---|---|---|
| Id | string | Unique identifier for the subscription | Required, generated by backend |
| FeedUrl | string | The URL entered by the user | Required, trimmed, non-empty |

## Relationships

- A subscription belongs to the current in-memory subscription list.
- The list is a simple collection with no persistence or user accounts.

## Notes

- The MVP intentionally keeps the model minimal to support rapid development and future extension.
