# Quickstart: MVP RSS Reader

## Prerequisites

- .NET 8 SDK installed
- A local terminal with access to the repository

## Validation Steps

1. Restore and build the backend and frontend projects.
2. Run the backend locally.
3. Run the frontend locally.
4. Open the app in a browser.
5. Enter a feed URL such as https://example.com/feed and submit it.
6. Confirm the subscription appears in the UI list.
7. Refresh the page and confirm the subscription remains visible for the current session.

## Expected Outcome

The app allows a user to add a subscription and see it appear in the list without requiring persistence or feed fetching.
